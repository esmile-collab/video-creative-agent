# 数据边界

## 可以进入公开仓库

- 通用代码、结构契约、Prompt（提示词）骨架和测试。
- 原创或明确授权的 Brief（任务简报）、脚本和策略卡。
- C 端公开页面的 URL（链接）、公开视频 ID、标题与最小来源说明。
- 不含业务效果的通用结构分析。

## 不进入公开仓库

- 私有业务效果、客户、人员和内部协作信息。
- Cookie（浏览器凭证）、Token（令牌）、API Key（接口密钥）和原始鉴权记录。
- 本机绝对路径、内部代码地址和运行会话标识。
- 未明确授权再分发的视频、音频、完整字幕和抽帧。
- 原始模型请求、响应、上下文快照和历史实验包。

公开源视频以外部引用方式进入 Demo（演示）。用户部署如需缓存媒体，应自行确认授权并配置独立存储。
