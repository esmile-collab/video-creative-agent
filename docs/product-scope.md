# 产品范围

## 首发定位

首发服务中文口播型知识内容和商业内容，交付脚本、分镜、校验报告与机器可读数据。

## 用户主流程

1. 填写 Brief（任务简报）、确认事实、创作许可和禁止项。
2. 系统对发布策略卡执行硬过滤、文本排序和 Top-1（第一名）选择。
3. 有合格卡时加载其生成视图；无合格卡时回退基础 Skill（生成规则）。
4. 模型生成脚本，用户编辑并确认版本。
5. 系统切分确认脚本、补齐连续时间并冻结原文。
6. 画面规划只新增 `visual_type（画面类型）` 和 `caption（画面描述）`。
7. 自动门禁通过后导出分镜和运行摘要。

## 质量边界

- 策略卡只迁移结构、表达与叙事机制。
- 当前主题或商品事实只来自本次 Brief（任务简报）和确认资料。
- 分镜阶段不改写确认脚本。
- 自动结构检查不替代人工画面质量判断。

## 后续范围

授权参考视频导入、ASR（自动语音识别）、OCR（光学文字识别）、抽帧、私有策略库、TTS（语音合成）、资产召回和成片合成按独立里程碑接入。
